# Examples

This directory will contain small, executable examples that demonstrate one
supported Qhapaq scenario at a time.

Examples must:

- Use public APIs and portable document formats.
- Pin operation and document versions where required.
- Avoid real credentials and private endpoints.
- Include expected output and a documented run command.
- Participate in automated build or smoke testing.

Large sample applications and performance benchmarks should use separately
documented locations if they are introduced.
