# Development Tools

This directory contains project-owned development utilities and tool
configuration that are not product packages.

Each tool must document its purpose, owner, invocation, inputs, outputs,
dependencies, trust boundary, and maintenance expectations. An MCP server stored
under a future `tools/mcp/<name>/` path is development tooling only; the
first-class Qhapaq MCP product belongs in the reference implementation.

Downloaded tool caches and generated output are not committed here.
