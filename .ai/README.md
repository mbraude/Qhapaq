# AI Development Assets

This area contains tool-neutral, reviewed assets for AI-assisted development.
It does not contain product runtime configuration or credentials.

- [prompts/](prompts/) contains reusable prompt templates for recurring work.
- [evaluations/](evaluations/) contains test cases and rubrics for measuring
  AI-generated changes.

Repository policy belongs in `AGENTS.md`, `CONTRIBUTING.md`, or development
documentation once those files are introduced. Assets here must identify their
consumer, expected inputs and outputs, safety constraints, and evaluation
method.
