# Development Documentation

This directory will document the supported contributor toolchain and practices,
including:

- Environment setup and pinned tool versions.
- Coding conventions and analyzer policy.
- Build, formatting, linting, and test commands.
- Test organization and fixture guidance.
- Documentation and schema authoring.
- Debugging, profiling, and release verification.

Commands documented here must match the scripts used by CI. Guidance will be
added as each toolchain decision is implemented.

Current guidance:

- [Coding conventions](coding-conventions.md) define repository-wide
  engineering requirements and defaults.
