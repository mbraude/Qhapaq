# Glossary of Three-Letter Abbreviations

This glossary defines three-letter abbreviations used in tracked Qhapaq source,
specification, and documentation files. It includes acronyms and initialisms
with technical or project-specific meaning.

The inventory excludes incidental three-character strings in hashes and test
data, grammar operators such as `NOT`, identifier prefixes such as `QHP`, and
`.NET`, which is a product name rather than an abbreviation.

| Abbreviation | Meaning | Use in this repository |
| --- | --- | --- |
| ADR | Architecture Decision Record | Records a significant architectural decision and its context and consequences. |
| API | Application Programming Interface | Describes a supported interface through which software components interact. |
| AOT | Ahead-of-Time | Refers to compiling an application before execution, particularly .NET Native AOT. |
| BMP | Basic Multilingual Plane | Identifies the first Unicode plane when discussing Unicode scalar handling. |
| CLI | Command-Line Interface | Provides Qhapaq's portable command-line process boundary. |
| CLR | Common Language Runtime | Refers to .NET runtime types and implementation details. |
| DAL | Data Access Layer | Names the implementation layer responsible for persistence-facing abstractions and behavior. |
| DNS | Domain Name System | Refers to name resolution and related network-policy checks. |
| DTO | Data Transfer Object | Describes an object used to carry data across a boundary. |
| IDE | Integrated Development Environment | Refers to developer tooling and machine-specific editor state. |
| IPC | Inter-Process Communication | Describes communication between processes. |
| IRI | Internationalized Resource Identifier | Distinguishes internationalized identifiers from the repository's URI profile. |
| ISO | International Organization for Standardization | Identifies standards such as ISO 8601. |
| MCP | Model Context Protocol | Provides Qhapaq's model-accessible discovery and execution surface. |
| NFA | Nondeterministic Finite Automaton | Defines the bounded regular-expression matching model in the portable pipeline specification. |
| OEM | Original Equipment Manufacturer | Appears in the licensing and commercial-use context. |
| OSI | Open Source Initiative | Distinguishes source availability from an OSI-approved open-source license. |
| RFC | Request for Comments | Identifies an Internet standards document, such as RFC 8785. |
| SDK | Software Development Kit | Refers primarily to the pinned .NET build toolchain. |
| SHA | Secure Hash Algorithm | Refers to SHA-256 hashes and checksums. |
| SQL | Structured Query Language | Identifies relational database connectors and their execution policies. |
| TCP | Transmission Control Protocol | Identifies a type of outbound network connection. |
| URI | Uniform Resource Identifier | Identifies resources under the repository's portable validation rules. |
| URL | Uniform Resource Locator | Identifies a resource location, such as a deployment preview. |
| UTC | Coordinated Universal Time | Defines the time standard used in date and time validation. |
| UTF | Unicode Transformation Format | Appears in encodings such as UTF-8 and UTF-16. |
| XDG | X Desktop Group | Appears in the name of the XDG Base Directory specification. |
| XML | Extensible Markup Language | Refers to documentation comments and a non-executable pipeline representation. |
