# Documentation

Documentation in this repository is canonical and organized by audience and
purpose:

- [architecture/](architecture/) records the current system model, decisions,
  and diagrams.
- [development/](development/) documents contributor toolchains and engineering
  practices.
- [guides/](guides/) contains task-oriented user and contributor guidance.
- [reference/](reference/) contains curated or generated technical reference.
- [wiki/](wiki/) contains source intended for any published project wiki.

Specifications under [specs/](../specs/) remain authoritative for normative
product behavior. Documentation should link to specifications rather than
silently redefining them.
